# Module Management

How to manage EPICS modules in this environment:

- [Add a Module](add-a-module.md) — the operator procedure for adding a
  module to the build system.
- [Module Management Conventions](module-management.md) — naming,
  dependency declaration, configure types, and validation rules.
- [Worked Example: Add pmac](new-module-example.md) — a complete example
  of adding a module with a custom configuration rule.
- [Use a Different Module Version](use-different-module-version.md) —
  install another version of a module beside the existing one.
- [Change a Module Repository URL](change-repository-url.md) — switch a
  module between a fork and the community repository.
- [Remove a Module](remove-a-module.md) — retire a module from the
  environment.
- [Module Dependency Audit](module-dependency-audit.md) — the design of
  `make check.module-deps` and the dependency evidence model.
